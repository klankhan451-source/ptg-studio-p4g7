How it works

  • Print: use “Print / Save PDF” and print at 100% scale. The pack includes a front cover, a host guide with every answer key, the game cards, certificates, tags, a scorecard and a back cover.
  • Editing: every question, word list and prompt in the built-in libraries can be changed in the “Edit content” boxes. One item per line; for questions with answers use Question | Answer.
  • Selling your packs? Your licence covers selling the finished party game packs you create (see the Commercial Use Licence in your download). The tool and your code themselves must never be shared or resold.
  • Projects are saved in this browser only. Switching occasion clears content edits, so save a project first if you want to keep them.
